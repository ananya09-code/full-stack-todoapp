# ✅ Flask To-Do App

A simple To-Do List web application built with Flask. Users can add, view, complete, and delete tasks.

## 🚀 Features

- Add new tasks  
- View all tasks  
- Mark tasks as completed  
- Delete tasks  
- Simple and clean UI  

## 🛠️ Tech Stack

- Python  
- Flask  
- HTML  
- CSS  
- SQLite  

## 📂 Project Structure

todo-app/
│
├── app.py
├── database.db
├── templates/
│   └── index.html
├── static/
│   └── style.css
└── README.md

## ⚙️ Installation

1. Clone the repository  
git clone your-repo-link

2. Go to project folder  
cd todo-app

3. Install Flask  
pip install flask

## ▶️ Run the App

python app.py

Then open in your browser:  
http://127.0.0.1:5000
